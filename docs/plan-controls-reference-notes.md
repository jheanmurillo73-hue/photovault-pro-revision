# Referencia de controles inferiores del plano

La captura revisada mide 1084 × 109 píxeles y se leyó en dos recortes horizontales con solapamiento. Confirma una franja inferior persistente que ocupa aproximadamente 109 píxeles de alto.

| Grupo visible | Controles identificados |
| --- | --- |
| Escala y rótulos | Plano 300%, Iconos 20% y Textos 25%, cada uno con acciones de disminuir y aumentar. |
| Operación de plano | Calibrar, contador de elementos ubicados y metraje de tubería, herramienta Mano y pantalla completa. |

La mejora solicitada debe evitar que esta franja permanezca abierta sobre el plano. Los grupos se convertirán en activadores compactos que abrirán paneles emergentes solo al interactuar con ellos.
