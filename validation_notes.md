# Validación de calibración

- El plano carga el control **Calibrar** cuando existe un JPG activo.
- Al activar el control, la interfaz muestra la instrucción para marcar el inicio del tramo de referencia.
- Tras marcar dos puntos sobre el plano, se abre el formulario **Calibrar distancia real** para ingresar los metros conocidos.
- Al guardar una referencia de 25 m, el control cambia a **Escala activa**, confirmando que la escala queda aplicada al plano.
- Al seleccionar una tubería, su panel contextual muestra la longitud calibrada y abre el editor de propiedades.
- El editor presenta una vista previa de evidencia y la acción **Reemplazar foto**, incluida antes de los campos operativos del elemento.
- Se cargó una imagen WebP temporal; el editor la optimizó y actualizó su vista previa sin errores. La prueba se cerró sin guardar para no modificar el registro de inspección.
