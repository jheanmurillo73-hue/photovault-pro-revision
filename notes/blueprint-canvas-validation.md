# Validación del lienzo de plano JPG

- La vista de mapa ya no carga ni muestra Google Maps Platform.
- Sin un JPG, la interfaz presenta una acción clara para cargar el plano.
- El estado inicial identifica tres elementos pendientes de ubicación y explica el flujo de clic manual.
- Un JPG de prueba se cargó y se ajustó automáticamente al área de trabajo.
- Una caja se seleccionó desde el panel, se ubicó con un clic y quedó marcada sobre el plano; el contador pendiente descendió de tres a dos.
- Una segunda caja también se ubicó correctamente; los controles conservan el estado y ahora queda un único tramo pendiente de ubicación.
- El último tramo pendiente se trazó con dos clics y quedó visible como línea con metraje; el contador de pendientes descendió a cero.
- Durante el modo de ubicación, los marcadores ya ubicados no interceptan clics, por lo que el usuario puede seleccionar cualquier punto del JPG para completar una caja, cámara o tramo.
